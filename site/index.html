Core Loop

Use The Same Training Cycle Until One Visible Behavior Changes

The atlas is strongest when it is used as a loop, not a library: diagnose the bottleneck, record a baseline, run reps, retest the same dimensions, then adjust the next cycle.

Open the full core loop on the practice page

Step 1

Diagnose

Name the main speaking bottleneck before choosing drills or content.
Step 2

Baseline

Record one comparable sample so the next cycle has usable evidence.
Step 3

Run Reps

Use daily templates or weekly sprints to repeat the right behavior.
Step 4

Retest

Score the same dimensions again instead of trusting memory or mood.
Step 5

Adjust

Decide whether to repeat, simplify, or switch based on visible change.
