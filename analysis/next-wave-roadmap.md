## Purpose

This file makes the repo’s current status explicit.

The workspace has already moved past raw capture and into a real first-wave
atlas, but it is not “complete” in the richer long-term sense described in the
project objective. This roadmap clarifies:

- what is already built
- what the highest-value next expansions are
- what can wait until later waves
