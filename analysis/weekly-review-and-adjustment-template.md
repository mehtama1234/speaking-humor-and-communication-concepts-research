# Weekly Review And Adjustment Template

Simple post-practice review template for deciding what to keep, what to drop,
and what to train next.

Date: August 10, 2026.

## Purpose

The speaking atlas now gives learners:

- diagnosis
- pathways
- weekly sprints
- prompt banks
- scorecards

What it still needed was a short review template for the end of the week.

Without that, learners often do one of two unhelpful things:

- keep switching directions without learning from the week
- keep repeating the same weak practice even after it stops producing change

This file gives the repo a cleaner adjustment layer.

If you know what failed this week but not the exact replacement move, pair this
file with `analysis/transcript-backed-concrete-speaking-approaches.md` so next
week’s plan starts from one named behavior.

## When to use this

Use this at the end of:

- a seven-day practice sprint
- one week of focused improvement actions
- one run through a starter-curriculum block

## How to use it

1. Review one baseline sample and one retest sample.
2. Fill this out in under 10 minutes.
3. Choose only one next adjustment for the next week.
4. Choose one exact move from
   `analysis/transcript-backed-concrete-speaking-approaches.md` for the next
   week.

## Weekly review template

### 1. What problem was I trying to solve?

Write one sentence only.

Examples:

- I freeze and rush when attention lands on me.
- My work updates are clear to me but unclear to other people.
- My humor feels forced and over-explained.

### 2. What did I actually practice?

List only the real reps you performed.

Examples:

- pressure-question five-second reset
- PREP argument reps
- pause replacement reps
- one baseline and one retest recording

### 3. What changed visibly?

Do not answer with feelings first. Answer with behavior.

Examples:

- I paused before answering instead of starting instantly.
- My recommendation arrived earlier.
- My delivery had more emphasis on the main line.
- I stopped explaining my own joke immediately after saying it.

### 4. What stayed weak?

Choose the one weakness that still showed up most clearly.

Examples:

- I still answered around the question before the point.
- I still sounded rushed in the first sentence.
- I still flattened the story into summary instead of scene.

### 5. Which score moved, if any?

Use the categories from `analysis/speaking-progress-scorecard.md`.

Write:

- the score that improved
- the score that stayed flat

If nothing moved, say so directly.

### 6. Why do I think the week worked or failed?

Choose the most likely reason, not every possible reason.

Common useful answers:

- I practiced one real weakness repeatedly.
- I mixed too many problems together.
- I read more than I repeated.
- I used inconsistent prompt tasks.
- I trained the wrong failure mode first.

### 7. What should I do next week?

Choose one:

- stay on the same pathway and repeat with better consistency
- keep the pathway but use a different drill
- switch to a different pathway because the diagnosis was wrong
- stay with the same skill but use easier prompts first

### 8. What will I not do next week?

This matters because most speaking improvement gets weaker through overload.

Examples:

- I will not add humor work while still fixing clarity.
- I will not judge improvement from memory alone.
- I will not switch to a harder prompt family until the current one improves.

## Best next-step routing

If the week improved one visible behavior:

- keep the same pathway
- keep the same prompt family
- repeat one more week before expanding

If the week produced no visible change:

- revisit `analysis/speaking-diagnosis-guide.md`
- simplify the practice load
- use fewer drills and more repetitions
- then pick one exact move from
  `analysis/transcript-backed-concrete-speaking-approaches.md`

If the week improved delivery but not clarity:

- move toward `concepts/structure-as-leverage.md`
- start with `Approach 5`, `Approach 6`, or `Approach 14` in
  `analysis/transcript-backed-concrete-speaking-approaches.md`

If the week improved clarity but not composure:

- move toward `concepts/speaking-under-pressure.md`
- start with `Approach 2`, `Approach 3`, or `Approach 15` in
  `analysis/transcript-backed-concrete-speaking-approaches.md`

If the week improved warmth but not humor:

- stay with connection work before forcing more jokes

## What this adds

This template closes the learner loop more cleanly:

- diagnose
- choose
- practice
- record
- score
- review
- adjust

That makes the repo feel more like a real training system and less like a set
of good materials waiting for the learner to invent their own process.
