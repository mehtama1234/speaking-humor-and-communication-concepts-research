# Andrew Tarvin Wave 1 Drill Candidates

First-pass drill candidates extracted from the `Andrew Tarvin` starter corpus.

Date: August 10, 2026.

If these drill candidates are being used to shape learner practice, pair them
with `analysis/transcript-backed-concrete-speaking-approaches.md`.

## Best candidate drills

### 1. Comic-triple drill

Transcript-backed basis:

- `#17 Rule of 3 vs Comic Triple`

Run it like this:

1. Write five lists of three around a familiar topic.
2. Make the first two items establish a clear pattern.
3. Make the third item break the pattern in a surprising but relevant way.
4. Read them aloud and keep only the ones that feel clean and quick.

Why it matters:

- gives a concrete non-mystical humor structure
- directly sharpens `Approach 17`

### 2. Humor-risk filter drill

Transcript-backed basis:

- `#28 The Dangers of Humor at Work`

Run it like this:

1. Take three jokes, lines, or humorous comments you might use at work.
2. Check each one against three failure modes:
   distract, divide, disparage.
3. Cut anything that fails one of the tests.
4. Rewrite the best line so it helps the message instead of stealing focus.

Why it matters:

- gives a practical business-safe humor filter
- strengthens `Approach 11` and `Approach 22`

### 3. Five-percent-better presentation drill

Transcript-backed basis:

- `#6 Prep for a Presentation Like a Pro`
- `#10 How to Hold a Memorable Presentation - Humor That Works`

Run it like this:

1. Deliver one presentation, update, or explanation.
2. Immediately note one thing to improve.
3. Re-deliver the same core material with that one improvement only.
4. Repeat until you have made the talk five percent better several times rather than trying to reinvent it.

Why it matters:

- builds iterative improvement instead of perfection paralysis
- deepens `Approach 5`

### 4. New-choice agility drill

Transcript-backed basis:

- `#12 How to Play Improv Game - New Choice`

Run it like this:

1. Start telling a simple story to a partner.
2. Every time the partner says `new choice`, replace the last idea with a different one.
3. Continue for two minutes without stopping the flow.
4. Focus on recovery speed, not elegance.

Why it matters:

- trains fast pivots
- improves spontaneity without fake confidence posturing

### 5. PowerPoint Karaoke drill

Transcript-backed basis:

- `#13 How to Play PowerPoint Karaoke (Example)`

Run it like this:

1. Pull a slide deck you have never seen or random visual prompts.
2. Speak through them as if you are the presenter.
3. Force yourself to create transitions and a point on the fly.
4. Review where you lost the thread and where you recovered well.

Why it matters:

- builds speaking-on-the-fly comfort
- sharpens `Approach 3` and `Approach 24`

### 6. Metaphor-generation drill

Transcript-backed basis:

- `#4 How to Create Metaphors Like Mark Normand`

Run it like this:

1. Take one dry concept you explain often.
2. Write three metaphors that could make it more vivid.
3. Test which one adds clarity rather than clutter.
4. Keep the metaphor that makes the idea easier to remember.

Why it matters:

- strengthens vividness and surprise
- improves memorable explanation design

### 7. Virtual-attention drill

Transcript-backed basis:

- `#29 How To Hold A Successful Virtual Event`
- `#31 The Hierarchy of Virtual Presentations`

Run it like this:

1. Record a two-minute virtual explanation on camera.
2. Re-record it with stronger opening energy, clearer transitions, and one explicit audience-engagement moment.
3. Compare which version is easier to stay with.
4. Keep the more watchable version as your new baseline.

Why it matters:

- makes remote speaking a trainable format
- adds modern transfer beyond stage speaking
