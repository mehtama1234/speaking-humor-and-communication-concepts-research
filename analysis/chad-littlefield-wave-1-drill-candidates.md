# Chad Littlefield Wave 1 Drill Candidates

First-pass drill candidates extracted from the `Chad Littlefield` starter
corpus.

Date: August 10, 2026.

If these drill candidates are being used to shape learner practice, pair them
with `analysis/transcript-backed-concrete-speaking-approaches.md`.

## Best candidate drills

### 1. One-more-question curiosity drill

Transcript-backed basis:

- `#185 Ask Powerful Questions To Create Conversations That Matter`
- `#423 How To Start A Conversation In A Business Meeting`

Run it like this:

1. In one conversation today, deliberately ask `one more real question` than
   your usual default.
2. Make it an open question, not a yes/no question.
3. After the conversation, note whether the extra question changed depth,
   trust, or usefulness.

Why it matters:

- directly attacks low-question-count autopilot
- builds `Approach 8` through repetition rather than theory

### 2. Leading-to-exploratory rewrite drill

Transcript-backed basis:

- `#347 How To Ask Questions To Get The Answers You Want`

Run it like this:

1. Write five questions you often ask in work or social settings.
2. Mark which ones are leading, narrow, or assumption-heavy.
3. Rewrite each one into a more exploratory `how` or `what` question.
4. Test one rewritten version in a real conversation the same day.

Why it matters:

- gives a practical route to psychological safety
- improves question quality in meetings and one-on-ones

### 3. No-question reflective-listening drill

Transcript-backed basis:

- `#351 How To Have A Conversation Without Asking Questions`

Run it like this:

1. In a five-minute conversation, avoid asking a new question for two full
   minutes.
2. Instead use verbatim reflection, translation, unstated-feeling reflection,
   or dot-connecting.
3. Track which reflection type keeps momentum best.

Why it matters:

- directly builds `Approach 25`
- prevents conversation from sounding interview-like

### 4. Road-trip method topic drill

Transcript-backed basis:

- `#337 How To Bring Up Topics In A Conversation`

Run it like this:

1. During a conversation, notice three pieces of extra data around or beneath
   the literal words.
2. Choose one and ask a reflective question rooted in it.
3. Repeat this twice in the same interaction.

Why it matters:

- trains the belief that conversation is expandable
- strengthens live topic generation

### 5. Awkwardness naming drill

Transcript-backed basis:

- `#369 How To Not Be Awkward In A Conversation`
- `#362 How To Get Out Of An Awkward Conversation`

Run it like this:

1. Prepare two simple lines you can use when a moment goes weird.
2. Examples:
   `That came out clumsier than I meant.`
   `Let me ask that in a better way.`
3. Use one line the next time a conversation stalls or lands awkwardly.

Why it matters:

- builds real-world recovery, not just confidence theater
- directly supports `Approach 9`

### 6. Topic-shift triad drill

Transcript-backed basis:

- `#397 How To Change The Topic Of Conversation`

Run it like this:

1. Practice three topic shifts out loud:
   funny, clever, and honest.
2. Funny:
   `Speaking of X, let's talk about Y.`
3. Clever:
   use a side detail from the current topic to pivot.
4. Honest:
   `I think we're going in circles. Can we shift to Y instead?`

Why it matters:

- creates concrete redirection options for meetings and social rooms
- useful for people who freeze when they want to steer

### 7. Meeting-opening participation drill

Transcript-backed basis:

- `#423 How To Start A Conversation In A Business Meeting`
- `#297 How To Start A Conversation In A Group, Virtually And In-Person`

Run it like this:

1. Start one meeting, group check-in, or class discussion with a connection
   prompt instead of content.
2. Use a question that lets people share something they know, noticed, or care
   about.
3. Observe whether the room feels safer or more active afterward.

Why it matters:

- transfers conversation design into work
- deepens `Approach 20` with visible room effects

### 8. Surprise-turn humor drill

Transcript-backed basis:

- `#210 How To Create Humor In Conversations`

Run it like this:

1. Write three ordinary observations from your day.
2. For each, write a version that ends with a surprising or sharply literal
   turn.
3. Test one in a low-stakes room and see whether it creates release or warmth.

Why it matters:

- trains humor as connection instead of forced joke-writing
- supports `Approach 11`

## Best first drills to operationalize

If only four drills from this corpus get elevated into learner-facing files
first, they should be:

1. no-question reflective-listening drill
2. leading-to-exploratory rewrite drill
3. awkwardness naming drill
4. topic-shift triad drill
