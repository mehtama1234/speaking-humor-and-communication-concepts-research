# Speaking Pattern Practice Recipes

Problem-first practice recipes that combine the right speaker model, the right
worked example, the right drill card, and one live challenge.

Date: August 10, 2026.

## Purpose

The repo now has strong practical layers:

- real speaker exemplars
- worked speaking situations
- context-first pattern selection
- move playbooks
- drill cards

This file adds one more execution layer:

- if you have one common speaking problem, what exact mini-stack should you run
  this week?

## How to use this file

1. Pick the recipe that matches your actual bottleneck.
2. Use the listed files in order.
3. Do not substitute a different problem halfway through the week.
4. Finish the live challenge before switching recipes.

Each recipe includes:

- the problem
- the speaker model
- the room-level deployment example when needed
- the before/after example
- the drill card
- the live challenge

## Recipe 1: My work updates sound messy and low-conviction

### Main pattern

- `Bottom line before backstory`

### Study in this order

1. `analysis/business-communication-curriculum.md`
2. `analysis/transcript-backed-concrete-speaking-approaches.md`
   Focus on:
   - `Approach 6: Compress before you expand`
   - `Approach 7: Remove low-status leakage`
   - `Approach 22: Aim for the next step, not immediate conversion`
3. `analysis/real-speaker-exemplars.md`
   Focus on:
   - Guy Kawasaki
   - Vinh Giang
4. `analysis/real-world-speaking-application-examples.md`
   Focus on:
   - `Example 3`
   - `Example 5`
5. `analysis/speaking-move-deployment-examples.md`
   Focus on:
   - `Example 3: Guy Kawasaki and next-step persuasion`
   - `Example 5: Matt Abrahams and point-first work communication`
6. `analysis/worked-speaking-situation-examples.md`
   Focus on:
   - `Giving a project update in a meeting`
7. `analysis/speaker-pattern-drill-cards.md`
   Focus on:
   - `Card 2: Bottom line before backstory`

### One drill to run

- record one 45-second update
- re-record it as a 20-second update
- keep the point in the first sentence both times

### Live challenge

In your next real update, say only:

- status
- main risk
- next step

### Success looks like

- the decision or status is obvious fast
- you sound more directional
- listeners ask fewer clarifying questions

- uncertainty sounds honest instead of evasive
- you stop narrating confusion
