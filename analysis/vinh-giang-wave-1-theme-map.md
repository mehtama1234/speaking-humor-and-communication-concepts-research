# Vinh Giang Wave 1 Theme Map

First-pass theme and subtheme map for `Vinh Giang Wave 1`.

Date: August 10, 2026.

If this map is being used to feed learner-facing practice design, pair it with
`analysis/transcript-backed-concrete-speaking-approaches.md` so each theme is
connected to named transcript-backed moves.

## Theme 1: Articulation and verbal polish

Core idea:
Speaking well is treated as a visible technical skill that changes how competent you sound.

Key sessions:

- `#1 How to Never Say 'Umm' & 'Ahh' Ever Again`
- `#5 How to Be Disgustingly Articulate And Well Spoken`
- `#11 How to Explain Anything To Anyone (Even If It's Complex!)`

Subthemes:

- filler-word reduction
- pause as replacement behavior
- clarity and verbal cleanliness
- explanation design

Best exact approaches:

- `Approach 2: Replace Fillers With Deliberate Silence`
- `Approach 14: Simplify Complex Ideas By Layering`

## Theme 2: Pressure response and anti-rambling control

Core idea:
Blanking, freezing, and rambling are framed as trainable communication failures.

Key sessions:

- `#17 How to Speak When All Eyes Are On You...`
- `#26 How to Stop Rambling (Even If Your Mind Goes Blank)`
- `#16 How to Answer ANY Question (Even If You Don't Know The Answer!)`

Subthemes:

- nervous-system management
- pause before response
- short answer structures
- buying time without sounding weak

Best exact approaches:

- `Approach 3: Pause, Frame, Then Answer`
- `Approach 15: Rehearse The Pressure Shape, Not Just The Content`

## Theme 3: Status, authority, and credibility

Core idea:
Many communication habits signal low status or weak professionalism even when the speaker is capable.

Key sessions:

- `#13 5 "Low Status" Speaking Habits That Make You Sound Weak`
- `#15 How To Stop Sounding Unprofessional At Work`
- `#22 How To Make A Strong First Impression (That Lasts)`
- `#6 How to Be Likeable AND Respected`

Subthemes:

- low-status cues
- professional polish
- warmth versus authority
- first-impression economics

Best exact approaches:

- `Approach 7: Remove Low-Status Leakage`
- `Approach 12: Build Respect Through Steadiness Instead Of Proving`
- `Approach 20: Lead With Warmth So Competence Can Land`
