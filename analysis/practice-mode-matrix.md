# Practice Mode Matrix

Comparison layer for choosing the right practice mode, not just the right
source.

Date: August 10, 2026.

## Purpose

The repo already has a source comparison matrix.

What it still needed was a practice comparison matrix:

- which route should a learner use depending on time horizon, urgency, and
  current state?

This file answers that directly.

Across every route below, if the learner still does not know the exact move to
practice, open `analysis/transcript-backed-concrete-speaking-approaches.md`
first and choose the named transcript-backed behavior before moving into the
larger mode.

## Matrix 1: Best route if you need something useful today

Best current choice:

- `Today mode`
- best file to open first: `analysis/daily-speaking-session-templates.md`
- if the move is still fuzzy:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it converts the repo into one actual session instead of one more planning
  exercise

Use this route when:

- you want one concrete practice block today
- consistency is more important than architecture

Do not use this route when:

- you need a full weekly or monthly plan more than a single session

## Matrix 2: Best route if you want one solid week of progress

Best current choice:

- `This-week mode`
- best file to open first: `analysis/weekly-practice-sprints.md`
- if diagnosis is clear but the exact move is not:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it gives enough repetition to create visible change without requiring
  month-long commitment

Use this route when:

- you already know the main failure mode
- you want seven days of focused reps and a retest

Do not use this route when:

- you are still unclear about the bottleneck

## Matrix 3: Best route if you want a serious structured start

Best current choice:

- `This-month mode`
- best file to open first: `analysis/month-one-speaking-training-plan.md`
- exact move layer:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it is the strongest current route for sequencing diagnosis, practice,
  feedback, retest, and redirection into one coherent block

Use this route when:

- you want a more disciplined training period
- you are willing to hold the same target long enough to measure it

Do not use this route when:

- you have not even run one honest daily or weekly cycle yet

## Matrix 4: Best route if a real event is close

Best current choice:

- `Before-event mode`
- best file to open first: `analysis/speaking-preflight-checklists.md`
- best companion if the event failure mode is known but the move is not:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it reduces last-minute failure risk better than opening a full curriculum

Use this route when:

- the event is soon
- execution quality matters more than deeper training design

Do not use this route when:

- the real issue is long-term skill building and there is no urgent event

## Matrix 5: Best route if you are practicing but not improving

Best current choice:

- `Stuck mode`
- best file to open first: `analysis/stalled-progress-troubleshooting-guide.md`
- first supporting route for a sharper intervention:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it narrows the problem instead of rewarding overload with more material

Use this route when:

- the week felt busy but not productive
- you no longer trust your original diagnosis

Do not use this route when:

- you have barely done enough reps to produce evidence yet

## Matrix 6: Best route if the repo feels rich but overwhelming

Best current choice:

- `practice stack bundles`
- best file to open first: `analysis/practice-stack-bundles.md`
- exact move bridge:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it groups the right files together by learner situation, which lowers setup
  friction without flattening the whole system

Use this route when:

- you like the repo but do not know which files belong together

Do not use this route when:

- you already know the exact daily, weekly, or monthly mode you need

## Matrix 7: Best route if you are new and want the least-risk start

Best current choice:

- `cold-start bundle`
- best file to open first: `analysis/first-session-quickstart.md`
- easiest named-move bridge after that:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it gives the safest path from zero context to diagnosis, recording, scoring,
  and one next step

Use this route when:

- you have not worked with the atlas before
- you want fast value without committing to a bigger structure yet

Do not use this route when:

- you already have baseline evidence and now need the next cycle

## Matrix 8: Best route if you need realistic rehearsal for a live situation

Best current choice:

- `simulation mode`
- best file to open first: `analysis/real-life-speaking-simulations.md`
- move-first bridge:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it turns abstract practice into situation-shaped rehearsal without requiring
  a real event to already be happening

Use this route when:

- you know the kind of moment you need to improve
- you want a practice rep that feels closer to life than a generic prompt
- you want to rehearse against a model that already resembles the room you are walking into

Do not use this route when:

- you still need basic diagnosis more than scenario rehearsal
- you need a last-minute checklist more than a transfer practice block

## Matrix 9: Best route if you want to watch strong examples before acting

Best current choice:

- `source-backed watch mode`
- best file to open first: `analysis/watch-before-you-practice-guide.md`
- best supporting exact-move layer:
  `analysis/transcript-backed-concrete-speaking-approaches.md`

Why:

- it gives you one or two high-leverage transcript-backed sessions and then
  points you directly to the next practice file instead of leaving you inside
  open-ended browsing

Use this route when:

- examples persuade you faster than summaries
- you want source-backed confidence before you drill
- you tend to learn better after seeing a strong model first

Best supporting transfer file after watching:

- `analysis/real-world-speaking-application-examples.md`

Why:

- it turns the watched speaker into a borrowed move, a matching room, and a
  stronger version you could actually say next

Do this immediately after watching:

1. pick one matching example from `real-world-speaking-application-examples`
2. rewrite the stronger version into your own words
3. use it in one recording or one live rep within 72 hours

Do not use this route when:

- you already know the exact practice block you need
- you are under time pressure and need an execution tool right now

## Matrix 10: Best route if you want an exact borrowed version before practicing

Best current choice:

- `borrowed-version mode`
- best file to open first: `analysis/real-world-speaking-application-examples.md`

Why:

- it gives you the shortest path from a strong speaker example to a matching
  real room and a stronger version you could actually use yourself

Use this route when:

- abstract advice is not enough
- you want to see the speaker, the room, and the adaptation in one place
- you want a practical borrowed version before a meeting, interview,
  presentation, or conversation

Do this next:

1. pick the example closest to your real room
2. rewrite the stronger version into your own vocabulary
3. use it in one recorded or live rep within 72 hours

Do not use this route when:

- you mainly want broad source exploration first
- you already know the exact drill and only need repetition

## What this adds

This matrix makes the repo more usable because it lets a learner compare
practice routes the same way they can already compare sources.

It answers a different practical question:

- not just which corpus is best
- but which operating mode is best right now
