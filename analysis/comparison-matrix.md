# Comparison Matrix

First-pass source and corpus comparison matrix for the speaking research atlas.

Date: August 10, 2026.

## Purpose

This file answers one of the most practical repo questions:

- Which source should someone use for which speaking problem?

The repo already has good corpus briefs, pathways, examples, and featured
sessions. What it lacked was a compact comparison layer that makes source
selection fast.

If you already know the problem but not the exact behavior to practice, pair
this file with `analysis/transcript-backed-concrete-speaking-approaches.md` so
source selection feeds directly into a named move instead of stopping at
channel choice.

## Matrix 1: Best source for freezing, blanking, and pressure speaking

Best current choice:

- `Ultraspeaking`
- close second: `Vinh Giang`

Why:

- `Ultraspeaking` is strongest on staying in character, confidence-through-composure, and anti-script recovery.
- `Vinh Giang` is stronger on nervous-system framing and rehearsal-based pressure control.

Use `Ultraspeaking` when:

- the person over-scripts
- the problem is visible panic or live recovery
  Strong move matches:
  `Approach 1`, `Approach 3`, `Approach 4`, `Approach 15`

Use `Vinh Giang` when:

- the person needs a more explicit rehearsal and pressure-management system
  Strong move matches:
  `Approach 2`, `Approach 7`, `Approach 10`, `Approach 21`

## Matrix 2: Best source for rambling and messy answers

Best current choice:

- `Think Fast Talk Smart`
- close second: `Vinh Giang`

Why:

- `Think Fast Talk Smart` is strongest on structure, openings, and audience-centered explanation.
- `Vinh Giang` is stronger on visible verbal weakness, filler reduction, and status loss from messy speech.

Use `Think Fast Talk Smart` when:

- the problem is organization
- the speaker needs clearer frameworks
  Strong move matches:
  `Approach 5`, `Approach 6`, `Approach 14`, `Approach 19`

Use `Vinh Giang` when:

- the problem is clutter, weak wording, or low-status delivery
  Strong move matches:
  `Approach 2`, `Approach 7`, `Approach 10`, `Approach 21`

## Matrix 3: Best source for sounding more alive and engaging

Use `Ultraspeaking` when:

## Matrix 4: Best source for workplace credibility and executive presence

Best current choice:

- `Vinh Giang`
- close second: `Think Fast Talk Smart`

Why:

- `Vinh Giang` is strongest on status signals, professionalism, first impressions, and credible verbal polish.
- `Think Fast Talk Smart` is stronger on calm strategic communication and structured workplace explanation.

Use `Vinh Giang` when:

- the problem is sounding weak, unprofessional, or lower-status
  Strong move matches:
  `Approach 7`, `Approach 12`, `Approach 20`, `Approach 21`

Use `Think Fast Talk Smart` when:

- the problem is communicating clearly upward, across teams, or in leadership settings
  Strong move matches:
  `Approach 5`, `Approach 13`, `Approach 19`, `Approach 22`

## Matrix 5: Best source for better explanation and audience clarity

Use `Think Fast Talk Smart` when:
