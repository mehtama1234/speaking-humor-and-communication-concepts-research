# Watch Before You Practice Guide

Transcript-backed viewing routes for learners who want one or two strong source
sessions before starting practice.

Date: August 10, 2026.

## Purpose

The atlas already has:

- featured sessions
- evidence moments
- pathways
- drills
- practice systems

What it still needed was a stronger bridge between source study and practice:

- if I want to watch something first, what exactly should I watch
- what evidence moment matters most
- what practice file should I open immediately after

This file answers that.

## How to use this file

Use this when:

- you learn better after seeing one strong example
- you want source-backed confidence before practicing
- the repo feels rich and you want the cleanest watch-to-practice route

Use one route only.

Watch one or two sessions, inspect the evidence moment if needed, then move
directly into practice instead of continuing to browse.

If you still need stronger concreteness after watching, move next into one of
these:

- `analysis/transcript-backed-concrete-speaking-approaches.md` if you want the
  cleanest named-move layer before examples, drills, or room-level transfer
- `analysis/real-speaker-exemplars.md` if you want named speaker models and
  adaptation notes
- `analysis/speaking-move-deployment-examples.md` if you want named speaker
  examples already translated into exact meeting, pressure, humor,
  presentation, or social situations
- `analysis/real-world-speaking-application-examples.md` if you want the
  actual person, the analogous real-life room, and a stronger version you
  could say next
- `analysis/worked-speaking-situation-examples.md` if you want before-and-after
  situations and stronger replacement wording
