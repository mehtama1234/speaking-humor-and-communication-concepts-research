# Source Scouting Operator Prompt

Operator-grade prompt and rubric for finding new speaking, humor,
storytelling, and communication sources that are actually worth adding to this
repo.

Date: August 10, 2026.

Use this file when scouting:

- new YouTube channels
- new playlists from already-approved channels
- second-wave and third-wave expansion sources
- exemplar-only corpora
- humor and storytelling expansion sources

Pair this file with:

- `analysis/project-objective.md`
- `analysis/youtube-channel-shortlist.md`
- `analysis/next-wave-source-shortlist.md`
- `analysis/transcript-backed-concrete-speaking-approaches.md`

## Core rule

Do not optimize for:

- popularity
- prestige
- views
- broad reputation
- inspiration
- "good content" in the abstract

Optimize for:

- `approach yield per transcript hour`

That means a strong source is one that can be mined for:

- reusable speaking moves
- concrete verbal examples
- weak-versus-strong contrasts
- drills and practice methods
- room-specific adaptations
- net-new mechanisms not already covered well in the corpus

## One-paragraph operator prompt

Find transcript-backed speaking sources that increase this repo's supply of
reusable speaking moves with concrete examples. Prefer channels, playlists, or
sessions that clearly teach a repeatable move, demonstrate it with actual live
wording, show weak-versus-strong contrast, and make the move usable in real
rooms such as meetings, interviews, presentations, social conversations,
storytelling, humor, persuasion, or difficult Q&A. Down-rank sources that are
mostly motivational, generic, repetitive, or hard to translate into drills,
examples, or named approaches. For every candidate, judge not "is this a good
channel?" but "will this source materially improve our move library, example
library, or drill layer beyond what we already have?"

## Expanded scouting instructions

When evaluating a source, try to answer:

1. What exact learner problem does this source help solve?
2. What specific moves is it likely to add?
3. Does it provide spoken wording, not just abstract advice?
4. Can its ideas be turned into drills?
5. Does it improve a weak area of the current corpus?
6. Is it mostly overlap, or does it add novelty?
7. Will its transcript density justify ingestion time?

The preferred candidate source pattern is:

1. clear verbal teaching
2. real examples or demonstrable scenes
3. repeatable moves
4. practical situations
5. teachable corrections
6. enough novelty to expand the current repo

## Hard filters

Strong candidates usually have at least two of these:

- clear named frameworks or moves
- example-driven teaching
- strong situational focus
- visible coaching or critique
- drills, prompts, or exercises
- frequent phrase-level guidance
- live analyses of speakers or interactions

Weak candidates often show up as:

- vague confidence talk
- personality worship
- body-language listicles with little transfer
- very broad self-help framing
- content optimized for entertainment but not extraction
- repeated versions of advice already captured well elsewhere

## Scoring rubric

Score each candidate from `1` to `5` on each dimension.

### 1. Approach density

- `1`: mostly broad commentary
- `3`: some reusable moves, unevenly
- `5`: frequent clear repeatable moves

### 2. Example quality

- `1`: mostly abstract explanation
- `3`: some examples, limited live wording
- `5`: strong concrete examples and usable wording

### 3. Drill potential

- `1`: hard to convert into practice
- `3`: some exercises possible
- `5`: directly produces drills or rehearsal patterns

### 4. Situational transfer

- `1`: unclear where the advice applies
- `3`: works in a few rooms
- `5`: clear transfer across real speaking situations

### 5. Novelty versus current corpus

- `1`: mostly overlap
- `3`: some new angle
- `5`: materially expands the current move library

### 6. Transcript efficiency

- `1`: too diffuse to justify ingestion
- `3`: mixed signal
- `5`: dense, extractable transcript value

## Decision thresholds

- `26-30`:
  ingest soon; high-value source
- `21-25`:
  likely worth adding if it fills a gap
- `16-20`:
  only add if a specific missing area needs coverage
- `15 or below`:
  probably not worth ingesting for this repo

## Practical selection rule

If two sources seem equally good, prefer the one that gives:

- better weak-versus-strong examples
- clearer phrase-level adaptation
- more direct drills
- more obvious room-level transfer
- stronger novelty against the current corpus

If one source is more famous but the other gives better approach extraction,
choose the less famous source.

## What success looks like

This scouting file is being used correctly if future source additions become:

- more targeted
- more practical
- less repetitive
- easier to convert into drills and examples
- more useful for `analysis/transcript-backed-concrete-speaking-approaches.md`

If scouting produces lots of interesting sources but few new approaches, the
selection rule is still too loose.
