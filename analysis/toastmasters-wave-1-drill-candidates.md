# Toastmasters International Wave 1 Drill Candidates

First-pass drill candidates extracted from the `Toastmasters International`
starter corpus.

Date: August 10, 2026.

If these drill candidates are being used to shape learner practice, pair them
with `analysis/transcript-backed-concrete-speaking-approaches.md`.

## Best candidate drills

### 1. Opening-scene drill

Transcript-backed basis:

- `#44 2025 Toastmasters World Champion of Public Speaking`
- `#79 2023 Toastmasters World Champion of Public Speaking`
- `#95 2022 Toastmasters World Champion of Public Speaking`

Run it like this:

1. Take one talk, answer, or story you usually start with explanation.
2. Rewrite the first 20 seconds as a scene, moment, or tension line.
3. Remove any throat-clearing introduction.
4. Read the new version aloud and check whether the direction is clearer faster.

Why it matters:

- builds stronger first-five-seconds control
- gives `Approach 4` an exemplar-backed practice route

### 2. One-moment story drill

Transcript-backed basis:

- `#65 Connect and Inspire Through Storytelling`
- `#109 A Conversation Between Two World Champions`

Run it like this:

1. Pick one story you usually summarize.
2. Find the exact moment where the change, surprise, or realization happened.
3. Retell only that moment with what was seen, heard, said, or felt.
4. Add the lesson only after the scene lands.

Why it matters:

- directly builds `Approach 18`
- turns abstract lessons into memorable scenes

### 3. Humor notebook drill

Transcript-backed basis:

- `#128 The Humor Workshop—Part I`

Run it like this:

1. Carry one running note labeled `humor notebook`.
2. Every day, write down three things that felt odd, frustrating, or lightly absurd.
3. At the end of the week, turn one note into a two-sentence observational bit.
4. Test it in low-stakes conversation or a team setting.

Why it matters:

- builds humor from noticing instead of force
- creates repeatable raw material for `Approach 11`

### 4. Hold-for-laughter drill

Transcript-backed basis:

- `#127 The Humor Workshop—Part II`
- `#109 A Conversation Between Two World Champions`

Run it like this:

1. Record a short story or humorous comment.
2. Mark the word or phrase where the turn lands.
3. Re-record while adding a full beat of silence after the turn.
4. Compare whether the second version sounds more confident and gives the laugh room to happen.

Why it matters:

- directly supports `Approach 17` and `Approach 21`
- prevents speakers from stepping on their own laugh moment

### 5. Rehearsed-spontaneity observation drill

Transcript-backed basis:

- `#127 The Humor Workshop—Part II`

Run it like this:

1. Before a talk or meeting, write down three observations about the room, audience, or setting.
2. Choose one you could use naturally if the moment opens up.
3. Deliver it conversationally rather than as a forced joke.
4. If it lands, continue lightly. If it does not, return to the main plan immediately.

Why it matters:

- builds audience-aware humor
- gives a practical version of observational spontaneity

### 6. PREP impromptu drill

Transcript-backed basis:

- `#87 Impromptu Speaking: How to Get Better at Speaking on the Spot`

Run it like this:

1. Pull a random prompt or question.
2. Answer it in four beats:
   point, reason, example, point.
3. Keep the whole answer under 45 seconds.
4. Repeat for five prompts in a row without restarting.

Why it matters:

- creates a durable anti-rambling fallback
- directly operationalizes `Approach 27`

### 7. Story-readiness drill

Transcript-backed basis:

- `#111 World Championship of Public Speaking®: Speaker Showcase`

Run it like this:

1. List three personal stories you might tell publicly.
2. For each one, ask:
   can I tell this without needing the audience to heal me?
3. Keep only the stories where you can now speak from clarity rather than raw processing.
4. Rewrite the chosen story around the message the audience can receive.

Why it matters:

- improves vulnerability calibration
- reduces over-sharing disguised as storytelling

### 8. Gesture-intent drill

Transcript-backed basis:

- `#88 How to Use Gestures and Body Language to Keep Your Audience Engaged`

Run it like this:

1. Record a one-minute explanation with your normal delivery.
2. Re-record it using only gestures that map to contrast, size, direction, or emphasis.
3. Remove restless or filler movement.
4. Compare which version looks easier to follow.

Why it matters:

- turns body language into meaning support
- gives a practical nonverbal upgrade path

## Best first drills to operationalize

If only four drills from this corpus get elevated into learner-facing files
first, they should be:

1. opening-scene drill
2. one-moment story drill
3. hold-for-laughter drill
4. PREP impromptu drill
