# Practice Stack Bundles

Ready-made file bundles for turning the speaking atlas into a practical system
instead of a collection of separate tools.

Date: August 10, 2026.

## Purpose

The atlas now has strong individual pieces:

- diagnosis
- daily sessions
- weekly actions
- weekly sprints
- month-one planning
- scorecards
- feedback and review loops

What it still needed was a bundle layer:

- if a learner has a specific goal, which four or five files should they use
  together?

This file answers that directly.

## How to use these bundles

- Pick one bundle based on your real need.
- Stay with it long enough to finish one cycle.
- Do not mix two bundles until one of them has clearly run its course.

Each bundle includes:

- the right starting file
- the right execution file
- the right measurement file
- the right review or adjustment file

Some bundles now also include:

- a worked situation layer
- a deployment-by-situation layer
- a real-speaker exemplar layer
- a reusable move and drill-card layer
- a multi-turn roleplay and scoring layer

If you want a more compact problem-first version of these bundles, also use:

- `analysis/speaking-pattern-practice-recipes.md`
