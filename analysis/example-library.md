# Example Library

First-pass cross-corpus example and exemplar library for the speaking research
repo.

Date: August 10, 2026.

## Purpose

The repo already has concepts, drills, and learner pathways. This file adds a
study layer for readers who want to examine especially useful sessions,
breakdowns, and example types.

These are not full transcripts or detailed annotations yet. They are the first
curated list of examples worth revisiting when studying a specific speaking
mechanism.

If you want the named move before choosing an example cluster, start with
`analysis/transcript-backed-concrete-speaking-approaches.md` first. This file
works best as the source-study layer built around those exact moves.
