# 30-Day Speaking Challenge

Four-week guided challenge for turning the speaking atlas into a practical
month of visible behavior change.

Date: August 10, 2026.

## Purpose

The repo already has:

- a month-one plan
- weekly sprints
- field missions
- roleplays
- partner-run practice
- review templates

This file adds a simpler challenge layer:

- what to do over the next 30 days if you want a serious but usable sequence
- how to connect private reps to live rooms every week
- how to start each week from one exact transcript-backed move instead of from
  abstract intent alone

This is not the most custom plan in the repo.

It is the cleanest challenge format.

## Who this is for

Best for learners who:

- want a real month-long challenge instead of choosing pieces manually
- want one practical structure with weekly themes and live assignments
- learn better from a visible challenge rhythm than from an open-ended atlas

## How to use this challenge

- Before each week, open
  `analysis/transcript-backed-concrete-speaking-approaches.md` and select one
  named move that matches the week’s bottleneck.
- Pick one primary lane:
  - work communication
  - hard questions and interviews
  - presentations and formal speaking
  - social warmth and humor
- Do not switch lanes unless Week 2 evidence says the diagnosis was wrong.
- Complete one live assignment each week.
- End each week with one short review.

## Weekly structure

Every week follows the same rhythm:

1. study one small set of materials
2. run 3 to 5 private reps
3. run 1 to 2 live reps
4. record one retest
5. review and adjust

## Week 1: Baseline and first visible win

### Goal

Get one clear diagnosis, one baseline, and one small visible improvement.

### Do

1. Use `analysis/speaking-diagnosis-guide.md`.
2. Record one baseline using `analysis/speaking-sample-prompt-bank.md`.
3. Score it with `analysis/speaking-progress-scorecard.md`.
4. Open `analysis/transcript-backed-concrete-speaking-approaches.md` and pick
   one named move that fits the diagnosis.
5. Pick one weekly sprint from `analysis/weekly-practice-sprints.md`.
5. Pick one matching deployment file:
   - `analysis/workplace-speaking-deployment-examples.md`
   - `analysis/social-humor-deployment-examples.md`
   - `analysis/presentation-interview-deployment-examples.md`
   - `analysis/speaking-move-deployment-examples.md`
   - `analysis/real-world-speaking-application-examples.md`
6. Use the exact move to shape the rep, not just the topic.
7. Complete one live mission from `analysis/live-field-missions.md`.

### Success by Sunday

- one baseline sample
- one main bottleneck
- one live rep completed
- one visible behavior that improved slightly

## Week 2: Pressure test the move

### Goal

See whether the improvement survives a little more realism.

### Do

1. Stay on the same lane.
2. Re-open `analysis/transcript-backed-concrete-speaking-approaches.md` and
   keep the same move unless the evidence says it was the wrong diagnosis.
3. Repeat the same sprint or a closely adjacent one.
4. Use one roleplay from `analysis/speaking-roleplay-packs.md`.
5. Score it with `analysis/roleplay-feedback-scorecard.md`.
6. If another person is available, run it with
   `analysis/partner-roleplay-facilitator-guide.md`.
7. Complete one second live mission from `analysis/live-field-missions.md`.

### Success by Sunday

- one better second-turn answer
- one clearer sense of what still breaks under pressure
- one real-world rep that felt more deliberate than Week 1

## Week 3: Expand into adjacent skill

### Goal

Add one adjacent behavior without losing the original one.

### Common expansions

- from pressure to structure
- from structure to delivery
- from warmth to follow-up depth
- from work clarity to pushback handling
- from formal openings to stronger closes

### Do

1. Keep the original lane.
2. Keep the original exact move live in at least one rep.
3. Add one adjacent file:
   - `analysis/speaker-pattern-playbook.md`
   - `analysis/speaker-pattern-drill-cards.md`
   - `analysis/speaking-pattern-practice-recipes.md`
4. Add one adjacent move from
   `analysis/transcript-backed-concrete-speaking-approaches.md`.
5. Choose one adjacent live mission.
6. If useful, run one partner roleplay again.
7. Record one comparison sample at the end of the week.

### Success by Sunday

- the original move still works
- one adjacent move shows up once in a live room
- the challenge feels more transferable, not just more familiar

## Week 4: Consolidate and decide month two

### Goal

Finish with evidence and a sane next step.

### Do

1. Re-record the same prompt family as Week 1.
2. Re-score it with `analysis/speaking-progress-scorecard.md`.
3. Fill out `analysis/weekly-review-and-adjustment-template.md`.
4. Compare:
   - baseline versus retest
   - first live mission versus last live mission
   - first cold roleplay versus later roleplay if used
5. Decide month two:
   - stay in the same lane
   - move one lane adjacent
   - switch to a curriculum track
   - keep using live missions but simplify the practice load
6. Write down the one exact approach that created the most transfer so month
   two starts from evidence, not memory.

### Success by Sunday

- one month-end retest
- one month-level review
- one month-two direction

## Minimum version of the challenge

If the full version feels heavy, do only this:

- one weekly sprint
- one deployment file
- one live mission
- one weekly review

That is still a legitimate 30-day challenge.

## What not to do

- do not switch target lanes every week
- do not do only private reps
- do not count reading as the challenge
- do not skip the weekly review
- do not add humor goals while clarity is still collapsing everywhere
