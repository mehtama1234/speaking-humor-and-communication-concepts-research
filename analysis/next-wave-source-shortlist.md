# Next-Wave Source Shortlist

Curated next-wave source shortlist for expanding the speaking research atlas
beyond the current ten transcript-backed corpora.

Captured on August 10, 2026.

If the goal is not just to ingest new sources but to know which exact moves
they should expand, pair this file with
`analysis/transcript-backed-concrete-speaking-approaches.md`.

For actual keep / reject decisions on new candidates, also use:

- `analysis/source-scouting-operator-prompt.md`
- `analysis/scouting-batch-1-humor-storytelling-social-speaking.md`

Wave-2 sourcing rule:

Choose the next source that most improves the repo's `approach inventory`,
not the next source with the broadest general communication coverage.

## Why this shortlist exists

The first wave established a strong base for:

- anti-script speaking
- confidence and recovery
- vocal polish and delivery
- structure and workplace clarity

What is still comparatively thin is:

- humor mechanics
- storytelling as spoken performance
- exemplar-heavy speech study

This shortlist prioritizes sources that fill those specific gaps rather than
simply adding more general speaking advice.

The current best scored expansion batch for those gaps is:

- `analysis/scouting-batch-1-humor-storytelling-social-speaking.md`

The intended selection logic is:

- more exact moves beats more generic frameworks
- more transcript-backed examples beats more motivational commentary
- more drill potential beats more inspirational content
- more gap-closing novelty beats more overlap
