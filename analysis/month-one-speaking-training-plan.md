# Month-One Speaking Training Plan

Four-week starting plan for turning the speaking research atlas into a
repeatable first month of practice.

Date: August 10, 2026.

## Purpose

The repo already has:

- diagnosis
- pathways
- focused weekly actions
- weekly sprints
- sample prompts
- scorecards
- listener feedback
- weekly review templates

What it still needed was a multi-week progression layer:

- how a serious learner should sequence these pieces across the first month
- when to pull in concrete example layers instead of staying abstract
- when to anchor a week around one exact transcript-backed move before
  expanding into examples, simulations, or broader curricula

This file is that missing bridge. It is not a lifelong program. It is a strong
month-one plan that helps a learner go from “I want to improve” to a full
four-week cycle with baseline, practice, review, retest, and adjustment.

If you want a simpler tracking layer for that month-long arc, also use:

- `analysis/30-day-speaking-challenge.md`
- `analysis/30-day-challenge-tracker.md`

## Who this is for

Best for learners who:

- want a more serious start than a one-week sprint
- do not want to invent their own month-one structure
- need a practical on-ramp before building a custom longer-term plan

## How to use this plan

- Choose one primary problem area.
- Do not train every weakness equally in month one.
- Use the same prompt family and same scorecard dimensions long enough to
  actually see change.
- Before each week, open
  `analysis/transcript-backed-concrete-speaking-approaches.md` and choose one
  named move that matches the current bottleneck.

## Week 0: Setup and baseline

Goal:

- identify the real problem and capture a usable starting point

Do:

1. Use `analysis/speaking-diagnosis-guide.md` to choose your primary failure
   mode.
2. Pick one relevant prompt family from
   `analysis/speaking-sample-prompt-bank.md`.
3. Record one baseline sample.
4. Score it with `analysis/speaking-progress-scorecard.md`.
5. If possible, get one round of outside signal using
   `analysis/listener-feedback-template.md`.
6. If the target still feels vague, first open
   `analysis/transcript-backed-concrete-speaking-approaches.md`.
7. If the target still feels vague after that, open one of:
   - `analysis/worked-speaking-situation-examples.md`
   - `analysis/real-speaker-exemplars.md`
   - `analysis/real-world-speaking-application-examples.md`

Output by the end of this week:

- one clear target problem
- one baseline sample
- one initial scorecard
- one chosen pathway or sprint

## Week 1: Run one focused sprint

Goal:

- train one failure mode with enough repetition to make visible change

Do:

1. Open `analysis/transcript-backed-concrete-speaking-approaches.md` and pick
   one exact move to protect all week.
2. Pick one relevant sprint from `analysis/weekly-practice-sprints.md`.
3. Run only that sprint for the week.
4. Pull in one concrete example layer if execution still feels too abstract.
5. Keep notes on what visibly changes instead of chasing subjective feelings.

If you need help choosing:

- freezing:
  use `Sprint 1` and start with `Approach 2`, `Approach 3`, `Approach 4`, or
  `Approach 15`
- rambling:
  use `Sprint 2` and start with `Approach 1`, `Approach 5`, `Approach 6`, or
  `Approach 14`
- workplace credibility:
  use `Sprint 3` and start with `Approach 3`, `Approach 5`, `Approach 13`, or
  `Approach 19`
- social awkwardness:
  use `Sprint 4` and start with `Approach 8`, `Approach 9`, `Approach 16`, or
  `Approach 20`
- humor naturalness:
  use `Sprint 5` and start with `Approach 11`, `Approach 17`, or
  `Approach 20`

Output by the end of this week:

- one completed sprint
- one short note on what changed and what stayed weak

## Week 2: Retest and adjust

Goal:

- compare baseline versus retest and decide what to do with evidence

Do:

1. Record a retest sample from the same prompt family.
2. Re-score the relevant dimensions in
   `analysis/speaking-progress-scorecard.md`.
3. If possible, gather one more round of outside feedback using
   `analysis/listener-feedback-template.md`.
4. Fill out `analysis/weekly-review-and-adjustment-template.md`.
5. Re-open `analysis/transcript-backed-concrete-speaking-approaches.md` and
   check whether the chosen move is still the right one.
6. If improvement is weak but the diagnosis still seems right, compare your rep
   against one matching item from `analysis/worked-speaking-situation-examples.md`
   or `analysis/real-speaker-exemplars.md`. If you still need a tighter
   transfer layer, also check `analysis/real-world-speaking-application-examples.md`.

Decision rule:

- if one visible behavior improved, stay with the same general skill one more
  week
- if nothing improved, simplify and revisit the diagnosis
- if a different weakness was more damaging than expected, shift pathways

Output by the end of this week:

- one retest sample
- updated scorecard
- one clear next-week adjustment

## Week 3: Deepen or redirect

Goal:

- either deepen the same skill or shift intelligently based on real evidence

Option A: Stay on the same problem

Use this if:

- one visible behavior improved
- the issue is still the main bottleneck

Do:

- repeat the same sprint with cleaner execution
- keep the same exact approach live unless the evidence clearly contradicts it
- or stay on the same pathway and use a different drill from that pathway
- and optionally add one matched example or exemplar before reps if the skill
  still feels conceptually understood but behaviorally weak

Option B: Redirect to the adjacent bottleneck

Use this if:

- the original diagnosis was too shallow
- another weakness is now clearly the bigger limiter

Common redirections:

- from pressure to structure
- from structure to delivery
- from warmth to humor timing
- from credibility to hard-question handling

Helpful concrete layer rule:

- if you still do not know the exact move to protect, start with
  `analysis/transcript-backed-concrete-speaking-approaches.md`
- if you understand the diagnosis but not the live wording, use
  `worked-speaking-situation-examples`
- if you understand the skill but want to study someone using it well, use
  `real-speaker-exemplars`
- if you want the person, the room, and the stronger borrowed version in one
  place, use `real-world-speaking-application-examples`

Output by the end of this week:

- either a stronger second cycle on the same skill
- or a cleaner second diagnosis and pathway choice

## Week 4: Consolidate and set month two

Goal:

- finish the first month with evidence and a sane next step

Do:

1. Record a month-one retest sample from the same prompt family.
2. Re-score the sample with the scorecard.
3. Fill out the weekly review template one more time, but this time for the
   month as a whole.
4. Choose your month-two direction:
   - stay with the same pathway
   - move to an adjacent pathway
   - switch into the business curriculum
   - switch into the broader starter curriculum
5. Note whether month two should stay example-heavy or move back toward a more
   direct drill-and-sprint emphasis.
6. Write down the one exact transcript-backed approach that transferred best so
   month two starts from evidence instead of vague memory.

Output by the end of this week:

- one month-one retest
- one month-level review
- one next-month direction

## What not to do in month one

- do not train all seven scorecard dimensions equally
- do not switch prompt families every few days
- do not judge progress from memory alone
- do not add advanced humor work before warmth and timing are more stable
- do not move on just because a week felt bad if visible behavior improved

- review
