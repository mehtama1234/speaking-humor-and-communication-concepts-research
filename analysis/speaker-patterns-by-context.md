# Speaker Patterns By Context

Fast route for choosing the right speaking move based on the actual situation in
front of you.

Date: August 10, 2026.

## Purpose

The repo now has:

- `analysis/real-speaker-exemplars.md`
- `analysis/worked-speaking-situation-examples.md`
- `analysis/speaker-pattern-playbook.md`
- `analysis/live-speaking-phrase-bank.md`
- `analysis/real-life-speaking-simulations.md`

That is strong coverage, but learners still hit one common friction point:

- "Which move should I use first in this specific kind of moment?"

This file solves that by organizing the strongest practical patterns by context
instead of by concept or source.

If you already know the room but not the exact move name, start with
`analysis/transcript-backed-concrete-speaking-approaches.md` first, then use
this file to choose the best context fit for that move.

## How to use this file

1. Start with the situation that is closest to a real moment on your calendar.
2. Match it to one item from
   `analysis/transcript-backed-concrete-speaking-approaches.md`.
3. Pick one pattern only.
4. Borrow the starter line shape and rewrite it into your own language.
5. Pair it with one adjacent file for deeper practice.
6. Use it live within the same week.

## 1. Work meeting: project update, status check, or recommendation

### Best first patterns

1. `Lead with the bottom line before the backstory`
2. `Handle uncertainty by naming what you know and what comes next`
3. `Acknowledge before you disagree`

Best exact approaches:

- `Approach 5`, `Approach 13`, `Approach 19`, `Approach 22`

### Use when

- your updates sprawl
- people seem unclear on what matters
- a recommendation gets pushback

### Starter line shapes

> "Quick update: we're on track, but the main risk is..."

> "My recommendation is to..."

> "I see the concern. The part I read differently is..."

### Real speaker anchors

- Guy Kawasaki
- Vinh Giang
- Sam Altman

### Best file pairing

- first: `analysis/speaker-pattern-playbook.md`
- then: `analysis/worked-speaking-situation-examples.md`

### Good first live rep

Use one of these patterns in your next real update instead of trying to sound
"better" in a general way.

## 2. Interview or executive Q&A: hard question, uncertainty, or pressure

Best exact approaches:

- you feel the urge to rush
- you start narrating confusion instead of answering

### Starter line shapes

> "What we do know is... and the next thing I'd check is..."

> "The short version is..."

## 3. Presentation or formal speaking: opening, clarity, memorability

### Best first patterns

1. `Start with a moment, not a topic heading`
2. `Let the lesson come through the scene, not your self-importance`
3. `Lead with the bottom line before the backstory`

Best exact approaches:

- `Approach 4`, `Approach 18`, `Approach 19`

### Use when

- your opening sounds procedural
- the talk feels informative but not memorable
- your explanation is technically fine but hard to care about

### Starter line shapes

> "Three weeks ago, a customer got stuck before they ever reached the part we were proud of. That's why this matters."

> "What changed me wasn't a big revelation from me. It was one sentence my mentor said after..."

> "The main point I want you to leave with is..."

### Real speaker anchors

- Matt Abrahams
- Tristan de Montebello
- Guy Kawasaki

### Best file pairing

- first: `analysis/speaker-pattern-playbook.md`
- then: `analysis/storytelling-and-memorability-curriculum.md`

### Good first live rep

Rewrite the first 20 seconds of one presentation using a moment-based opening
instead of a polite topic heading.

- you over-focus on sounding native instead of sounding clear

### Starter line shapes

> "My recommendation is..."

> "What matters most here is..."
