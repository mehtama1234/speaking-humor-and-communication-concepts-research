# Starter Corpus Selection

Curated first-wave transcript targets for the speaking, humor, and
communication research workspace.

Date: August 10, 2026.

If the goal is not just to choose starter corpora but to know which exact moves
they should surface first, pair this file with
`analysis/transcript-backed-concrete-speaking-approaches.md`.

## Why starter slices are necessary

The first three source manifests are now captured, but two of them are too
large for a sensible first transcript pass:

- `Ultraspeaking Videos`: 108 videos
- `Vinh Giang Videos`: 388 videos
- `Think Fast Talk Smart Videos`: 346 videos

That means the right move is:

- use a manageable first slice from `Ultraspeaking`
- use narrower, more targeted starter slices from `Vinh Giang`
- use narrower, more targeted starter slices from `Think Fast Talk Smart`

## Command flow

First transcript capture:

```bash
python3 scripts/download_youtube_playlist_transcripts.py \
  --course-root . \
  --manifest raw-material/youtube/starter-manifests/ultraspeaking-wave-1.json
```

This writes corpus-specific outputs under:

- `raw-material/youtube/transcripts/ultraspeaking-wave-1/`
- `raw-material/youtube/playlists/ultraspeaking-wave-1.json`

Then build the session inventory:

```bash
python3 scripts/build_course_session_inventory.py \
  --course-root . \
  --manifest raw-material/youtube/starter-manifests/ultraspeaking-wave-1.json \
  --output analysis/ultraspeaking-wave-1-session-inventory.md
```

Repeat the same pattern for:

- `vinh-giang-wave-1.json`
- `think-fast-talk-smart-wave-1.json`
- `charisma-on-command-wave-1.json`
- `matthew-dicks-wave-1.json`
- `jefferson-fisher-wave-1.json`
