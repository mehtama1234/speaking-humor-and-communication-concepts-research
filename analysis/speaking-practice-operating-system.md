# Speaking Practice Operating System

High-level operating map for using the speaking atlas across today, this week,
this month, before a real event, and when progress stalls.

Date: August 10, 2026.

## Purpose

The repo now has strong layers for:

- diagnosis
- daily execution
- weekly action
- weekly sprints
- monthly sequencing
- troubleshooting
- event preparation

What it still needed was one explicit operating map:

- when should each layer be used?
- when should example-first materials be used?
- when should transcript-backed approach inventories be used before the other
  practice layers?

This file answers that directly.

## The five operating modes

Use the atlas in one of five modes:

1. `Today mode`
2. `This-week mode`
3. `This-month mode`
4. `Before-event mode`
5. `Stuck mode`

If you pick the wrong mode, the repo feels more complicated than it is.

## Mode 1: Today mode

Use this when:

- you want to practice today
- you only need one session structure
- you do not need a full planning cycle first

Open these files:

1. `analysis/daily-speaking-session-templates.md`
2. `analysis/transcript-backed-concrete-speaking-approaches.md`
   if you want a named move before picking the day’s rep
3. `analysis/focused-improvement-actions.md`
4. `analysis/speaking-sample-prompt-bank.md`
5. `analysis/worked-speaking-situation-examples.md`
   if you need a concrete before-and-after model before your rep
6. `analysis/speaking-move-deployment-examples.md`
   if you want a named speaker example already translated into the kind of room
   you are practicing for
7. `analysis/real-world-speaking-application-examples.md`
   if you want the actual person, the analogous real-life situation, and an
   exact stronger version to adapt before the rep
8. `analysis/speaking-roleplay-packs.md`
   if the challenge is likely to include a harder second turn
9. `analysis/partner-roleplay-facilitator-guide.md`
   if another person is available to run the rep with realistic escalation
10. `analysis/live-field-missions.md`
   if the main need is one real-world assignment instead of another private rep

Minimum output:

- one short session completed
- one recording or one live rep
- one note about what improved or broke

Do not:

- redesign your whole pathway
- open five concept pages first

## Mode 2: This-week mode

Use this when:

- you already know the main failure mode
- you want one real week of repetition
- you want evidence at the end of the week

Open these files:

1. `analysis/learner-pathways.md`
2. `analysis/transcript-backed-concrete-speaking-approaches.md`
   if the weekly target still feels too conceptual and you need exact moves
3. `analysis/weekly-practice-sprints.md`
4. `analysis/speaking-progress-scorecard.md`
5. `analysis/weekly-review-and-adjustment-template.md`
6. `analysis/real-speaker-exemplars.md`
   if the weekly target still feels too abstract
7. `analysis/speaking-move-deployment-examples.md`
   if you understand the move but still need stronger room-level transfer
8. `analysis/real-world-speaking-application-examples.md`
   if you want exact borrowed versions before trying the move in your own room
9. `analysis/weekly-plans-by-learner-type.md`
   if you want the whole week sequenced for your learner type

Minimum output:

- one weekly sprint completed
- one retest or comparison sample
- one next-week adjustment

Do not:

- run two weekly sprints together
- keep changing the target problem midweek

## Mode 3: This-month mode

Use this when:

- you want a serious month-one training block
- you want a cleaner baseline-to-retest progression
- you do not want to invent the monthly sequence yourself

Open these files:

1. `analysis/month-one-speaking-training-plan.md`
2. `analysis/speaking-diagnosis-guide.md`
3. `analysis/speaking-sample-prompt-bank.md`
4. `analysis/speaking-progress-scorecard.md`
5. `analysis/30-day-speaking-challenge.md`
   if you want the month to feel like a guided challenge instead of only a
   planning sequence
6. `analysis/practice-stack-bundles.md`
   especially `Bundle 9` if examples drive learning better than frameworks
7. `analysis/real-world-speaking-application-examples.md`
   if month one is stalling because you still need a more exact transfer layer

Minimum output:

- one baseline
- one monthly route
- one month-one retest
- one month-two direction

Do not:

- switch routes every few days
- treat month one like casual browsing

## Mode 4: Before-event mode

Use this when:

- a meeting is coming
- an interview is coming
- a presentation is coming
- a social situation matters soon

Open these files:

1. `analysis/context-based-speaking-routes.md`
2. `analysis/speaking-preflight-checklists.md`
3. `analysis/daily-speaking-session-templates.md`
4. `analysis/listener-feedback-template.md`
5. `analysis/worked-speaking-situation-examples.md`
   if you need one realistic wording model before the event
6. `analysis/speaking-move-deployment-examples.md`
   if you want a stronger bridge from named speaker example to the exact kind
   of event you are walking into
7. `analysis/real-world-speaking-application-examples.md`
   if you want the speaker, the room, and the exact adaptation in one place
8. `analysis/speaking-roleplay-packs.md`
   if the event is likely to include sharper follow-up pressure
9. `analysis/partner-roleplay-facilitator-guide.md`
   if someone can run the event rehearsal with you

Minimum output:

- one live-situation rehearsal
- one cleaned-up opening or hard answer
- three carry-in reminders

Do not:

- start a full curriculum the hour before the event
- overload yourself with new concepts

## Mode 5: Stuck mode

Use this when:

- you practiced and nothing changed
- you feel overloaded by too many routes
- you are no longer sure what the main bottleneck is

Open these files:

1. `analysis/stalled-progress-troubleshooting-guide.md`
2. `analysis/speaking-diagnosis-guide.md`
3. `analysis/time-budget-practice-guide.md`
4. `analysis/weekly-review-and-adjustment-template.md`
5. `analysis/real-speaker-exemplars.md`
   or `analysis/worked-speaking-situation-examples.md`
   if the missing piece is still concrete modeling rather than effort
6. `analysis/speaking-move-deployment-examples.md`
   if what is missing is not motivation but a more exact real-situation example
7. `analysis/real-world-speaking-application-examples.md`
   if you need to see the speaker model and the borrowed version side by side

Minimum output:

- one clearer diagnosis
- one narrower next target
- one smaller practice shape

Do not:

- solve the plateau by adding more material
- confuse frustration with lack of progress evidence

## Fast decision rule

If the question in your head is:

- `What should I do today?`
  Use `Today mode`
- `What should I work on this week?`
  Use `This-week mode`
- `How do I train seriously this month?`
  Use `This-month mode`
- `What should I do before the real event?`
  Use `Before-event mode`
- `Why am I not improving?`
  Use `Stuck mode`

## Best mode by learner state

If you are:

- new: start with `Today mode`, then move to `This-week mode`
- motivated but inconsistent: start with `Today mode`
- structured and serious: start with `This-month mode`
- under time pressure: start with `Before-event mode`
- discouraged: start with `Stuck mode`

## Common misuse of the atlas

Most misuse comes from mixing modes:

- using monthly planning when you actually need one daily session
- reading concept pages when you actually need a weekly sprint
- adding new material when the real problem is poor review and adjustment

The fix is usually not more information.

The fix is choosing the right operating mode.

Sometimes the fix is also choosing the right example layer:

- `real-speaker-exemplars` when you need to study a person using the move well
- `worked-speaking-situation-examples` when you need a realistic weak versus
  strong replacement
- `speaking-move-deployment-examples` when you need a named speaker plus the
  exact kind of room where you should deploy the move next
- `real-world-speaking-application-examples` when you want the observed move,
  the matching real room, and a strong adaptation line in one place
- `speaking-roleplay-packs` when your first answer is acceptable but the next
  turn is where the rep actually breaks
- `partner-roleplay-facilitator-guide` when a second person is available and
  you want the roleplay to stay realistic and scoreable
- `live-field-missions` when the real gap is not understanding or rehearsal,
  but actually using the move in a live room this week
