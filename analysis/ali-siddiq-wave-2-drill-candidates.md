# Ali Siddiq Wave 2 Drill Candidates

Candidate exercises derived from the transcript-backed source read. These are
transfer hypotheses, not yet validated learner interventions.

## 1. Consequence-first opening

1. Pick a routine presentation topic.
2. Write the opening as a concrete moment, decision, or consequence in two
   sentences.
3. Give only the context needed to understand the next sentence.
4. Ask a listener what question they expected the talk to answer.

Source anchors: `#47`, `#151`, `#198`.

## 2. Scene-to-principle conversion

1. Choose one real incident related to the topic.
2. List the people, object, place, visible action, and changed condition.
3. Tell the scene in 45 seconds.
4. Add the general lesson only after the listener can picture the event.

Source anchors: `#4`, `#56`, `#118`.

## 3. Escalation ladder

1. Write a five-beat story or case study.
2. For each beat, state what changed and what choice became harder.
3. Remove beats that add intensity but do not change the situation.
4. Rehearse the transitions using “because of that…” or “which meant…”

Source anchors: `#33`, `#64`, `#82`.

## 4. Callback with changed meaning

1. Choose one image or phrase from your opening.
2. Reintroduce it at the close.
3. Make the return reveal what the audience now understands.
4. Test whether the callback works for a listener who heard the opening only
   once.

Source anchors: `#151`, `#198`.

## 5. Clean public repair

1. Give a two-minute explanation while a partner introduces one factual
   correction or ambiguity.
2. Repair in one sentence: acknowledge, correct, and return to the point.
3. Do not add an apology monologue or restart the entire explanation.
4. Review whether the listener could still state the main point.

Source bridge: recovery and audience-aware adjustment; requires independent
validation before promotion.

## 6. Humor transfer safety check

1. Take one humorous line from a personal story.
2. Remove material that depends on humiliating a non-consenting person or on
   insider context.
3. Keep only the observation that helps the audience see the situation.
4. Run the result through the existing distract/divide/disparage filter from
   the Andrew Tarvin corpus.

Source bridge: Ali Siddiq storytelling plus `Approach 11` safety constraints.
