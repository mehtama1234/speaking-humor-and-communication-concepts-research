# 30-Day Challenge Tracker

Simple tracking sheet for running the repo's 30-day speaking challenge without
having to invent your own spreadsheet or notebook structure.

Date: August 10, 2026.

## Purpose

The repo already has:

- `analysis/30-day-speaking-challenge.md`
- `analysis/speaking-progress-scorecard.md`
- `analysis/weekly-review-and-adjustment-template.md`
- `analysis/live-field-missions.md`

What it still needed was a cleaner tracking layer:

- what to mark each week
- how to log reps quickly
- where to compare baseline and retest
- how to keep the month visible
- where to record the one exact transcript-backed move being trained that week

This file gives the month-long challenge an operating sheet.

## How to use this file

1. Fill the setup section once at the start.
2. Use the weekly log briefly after each rep.
3. Do not write essays.
4. Update it in under 3 minutes after each session.
5. Review it each Sunday before picking the next adjustment.
6. Track the exact approach for the week using
   `analysis/transcript-backed-concrete-speaking-approaches.md`.

Keep each entry this short:

```text

Did I actually do it? yes / no / partly

```
