# Featured Sessions

First-pass curated entry points across the current transcript-backed speaking
corpora.

Date: August 10, 2026.

## Purpose

This file answers a practical learner question the repo did not yet answer
directly enough:

- If I only watch a handful of sessions first, which ones should they be?

These are not simply the longest sessions. They are the sessions that appear to
offer the strongest mix of clarity, leverage, reusability, and concept value
for the current repo.

If you already know the learner problem but not the exact move to extract from
the session, start with `analysis/transcript-backed-concrete-speaking-approaches.md`
first. This file works best as the watch-first layer for those named moves.
