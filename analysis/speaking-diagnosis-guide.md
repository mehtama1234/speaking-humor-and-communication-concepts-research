# Speaking Diagnosis Guide

Quick-start diagnosis layer for choosing the right entry point in the speaking
research atlas.

Date: August 10, 2026.

## Purpose

The repo already has:

- concept pages
- drills
- learner pathways
- focused improvement actions
- starter curricula
- weekly practice sprints

What a new learner may still not know is:

- what their main problem actually is

Many speaking failures look similar from the outside. Someone may say
"I’m bad at speaking," when the real issue is one of these:

- pressure collapse
- weak structure
- flat delivery
- low-status wording
- poor conversational warmth
- forced humor
- weak question handling

This file is a practical diagnosis layer to help the learner choose the right
starting path.

## How to use this guide

1. Find the symptom that sounds most like your real failure mode.
2. Read the likely underlying issue carefully.
3. Start with the linked pathway, sprint, and concept instead of trying to fix
   everything at once.
4. If the diagnosis still feels too abstract, use:
   - `analysis/transcript-backed-concrete-speaking-approaches.md` for named
     transcript-backed moves, when to use them, and what stronger versions
     sound like
   - `analysis/worked-speaking-situation-examples.md` for realistic weak versus
     strong replacements
   - `analysis/real-speaker-exemplars.md` for actual named speakers using the
     move well
   - `analysis/real-world-speaking-application-examples.md` for the real
     person, the matching room, and a stronger version you could actually use

## Diagnosis 1: “I know what I mean, but I freeze when attention lands on me.”

Likely underlying issue:

- pressure handling, not lack of knowledge

Typical visible behaviors:

- rushing the first sentence
- blanking when interrupted
- apologizing when you lose your place
- treating pause as visible failure

Best starting path:

- `analysis/learner-pathways.md`
  Use `Pathway 1: From freezing to composed spontaneous speaking`

Best first sprint:

- `Sprint 1: Stop freezing and start answering more calmly`

Best first concepts:

- `concepts/speaking-under-pressure.md`
- `concepts/pause-as-strength.md`

Best concrete models:

- `analysis/transcript-backed-concrete-speaking-approaches.md`
  `Approach 1`, `Approach 3`, `Approach 4`, or `Approach 15`
- `analysis/worked-speaking-situation-examples.md`
  `Situation 2`
- `analysis/real-speaker-exemplars.md`
  `Sam Altman`
- `analysis/real-world-speaking-application-examples.md`
  `Example 1`

- memorizing more exact wording
- trying to “sound confident” before fixing visible recovery

## Diagnosis 8: “I’m trying to improve everything at once and getting nowhere.”

Likely underlying issue:

- no practice constraint

Typical visible behaviors:

- reading many notes with little repetition
- mixing delivery, structure, and humor in one session
- switching drills before they have any chance to work

Best starting move:

- choose one pathway
- choose one sprint
- repeat one drill for three separate days before judging it

Best linked files:

- `analysis/starter-curriculum.md`
- `analysis/weekly-practice-sprints.md`
- `analysis/focused-improvement-actions.md`

## Fast triage version

If you need the fastest possible diagnosis:

- freeze under attention:
  start with `speaking under pressure`
- ramble and lose the point:
  start with `structure as leverage`
- sound weak at work:
  start with `executive presence`
- sound flat:
  start with `musicality`
- feel awkward socially:
  start with `curiosity and conversational depth`
- force humor:
  start with `humor timing and collaborative play`
- break under objections:
  start with `hard question handling`

## What this adds

This guide makes the repo more usable for a cold reader because it answers a
question that the other layers only answered indirectly:

- which failure mode do I actually have, and what should I start with because
  of that?
