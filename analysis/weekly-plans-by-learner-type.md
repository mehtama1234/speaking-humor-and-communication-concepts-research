# Weekly Plans By Learner Type

Ready-to-run seven-day plans for common learner types using the speaking atlas.

Date: August 10, 2026.

## Purpose

The repo already has:

- weekly sprints
- month-one planning
- practice bundles
- problem-first recipes
- learner-style case studies

This file adds a clearer weekly course layer:

- if you are a certain kind of learner, what should your next seven days look
  like?

## How to use this file

1. Pick the learner type closest to your real situation.
2. Run only that plan for one week.
3. Do not switch learner types midweek unless the diagnosis was clearly wrong.
4. At the end of day seven, decide whether to repeat, deepen, or redirect.

If the weekly plan still feels too broad, open:

- `analysis/transcript-backed-concrete-speaking-approaches.md`

That file gives the shortest route from learner type to named move.

## Learner Type 1: Busy professional with weak work communication

### Best for

- messy updates
- soft recommendations
- low-conviction professional speech

### Day 1

- open `analysis/business-communication-curriculum.md`
- open `analysis/transcript-backed-concrete-speaking-approaches.md`
  Focus on:
  - `Approach 6`
  - `Approach 7`
  - `Approach 22`
- open `analysis/real-speaker-exemplars.md`
  Focus on:
  - Guy Kawasaki
  - Vinh Giang
- open `analysis/real-world-speaking-application-examples.md`
  Focus on:
  - `Example 3`
  - `Example 5`

### Day 2

- open `analysis/worked-speaking-situation-examples.md`
  Focus on:
  - `Giving a project update in a meeting`
- write one real update using:
  - status
  - risk
  - next step

### Day 3

- open `analysis/speaker-pattern-drill-cards.md`
  Focus on:
  - `Card 2: Bottom line before backstory`
- record one 45-second update and one 20-second update

### Day 4

- open `analysis/speaking-pattern-practice-recipes.md`
  Focus on:
  - `Recipe 1`
- run the live challenge in a real meeting if possible

### Day 5

- open `analysis/live-speaking-phrase-bank.md`
  Focus on:
  - `Giving clearer work updates`
- rewrite three weak work phrases you actually use

### Day 6

- deliver one real decision-oriented update
- ask whether the listener can repeat the decision back in one sentence

### Day 7

- score one fresh update with `analysis/speaking-progress-scorecard.md`
- write one note:
  - what sounded stronger
  - what still sounded weak
