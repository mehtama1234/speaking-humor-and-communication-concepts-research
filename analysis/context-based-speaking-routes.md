# Context-Based Speaking Routes

Practical starting routes based on the real-life speaking situation rather than
only the underlying failure mode.

Date: August 10, 2026.

## Purpose

The atlas already routes learners well by:

- failure mode
- sprint
- month-one progression

What it still needed was a context layer.

Many learners do not think in terms like:

- structure weakness
- pressure collapse
- warmth deficit

They think in terms like:

- I need to be better in meetings
- I keep fumbling interviews
- my presentations lose the room
- I want to be better in social conversation

This file translates those real-life contexts into the right parts of the
atlas.

## How to use this guide

1. Start with the real situation where your speaking quality matters most.
2. Use the linked pathway, curriculum, and drill suggestions.
3. Stay with that route long enough to produce visible change before adding a
   second context.

If the route still feels too broad after you identify the situation, open:

- `analysis/transcript-backed-concrete-speaking-approaches.md`

That file is the fastest bridge from context to the named move you should try
first.

## What this adds

This guide makes the atlas easier to use in real life because many learners can
name the situation faster than they can name the mechanism.

It gives the repo a new entry mode:

- not only “what weakness do I have?”
- but also “what real speaking situation do I need to improve first?”
