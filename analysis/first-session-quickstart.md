# First Session Quickstart

Cold-start guide for getting immediate value from the speaking research atlas
in the first 30 to 60 minutes.

Date: August 10, 2026.

## Purpose

The atlas now supports:

- a first-week sprint
- a first-month plan
- diagnosis
- recording prompts
- scorecards
- feedback and review loops

What it still needed was a true entry point for a brand-new reader:

- what to do in the first sitting before any larger commitment
- where to go if the learner still needs a concrete model before practicing
- where to go if the learner wants an exact transcript-backed approach instead
  of a broader concept summary

This quickstart is for that first session.

## Who this is for

Best for learners who:

- are opening the repo for the first time
- want immediate value without reading everything
- need a clean first step before choosing a longer route

## What this first session should accomplish

By the end of the first 30 to 60 minutes, the learner should have:

- identified one likely speaking bottleneck
- recorded one short baseline sample
- scored that sample at a rough level
- chosen one next step for the coming week

Notably, the learner should not try to:

- fix every weakness at once
- read every concept page
- choose a month-long program before seeing one baseline sample

## 30-minute version

### Step 1: Diagnose the likely bottleneck

Spend 5 minutes with:

- `analysis/speaking-diagnosis-guide.md`

Choose the one description that sounds most true right now.

### Step 2: Record one short baseline sample

Spend 5 to 10 minutes with:

- `analysis/speaking-sample-prompt-bank.md`

Pick one prompt family that matches your diagnosis and record one sample.

Good first choices:

- freezing:
  use `Pressure answers`
- rambling:
  use `Clarity and explanation`
- workplace credibility:
  use `Work updates and recommendations`
- social awkwardness:
  use `Warmth and conversation entry`

### Step 3: Score only the relevant dimensions

Spend 5 minutes with:

- `analysis/speaking-progress-scorecard.md`

Do not score everything deeply. Score only the two or three dimensions most
connected to the chosen problem.

### Step 4: Pick one next step

Spend 5 minutes choosing one:

- one section from
  `analysis/transcript-backed-concrete-speaking-approaches.md`
- one section from `analysis/focused-improvement-actions.md`
- or one sprint from `analysis/weekly-practice-sprints.md`
- and, if the route still feels too abstract, one of:
  - `analysis/worked-speaking-situation-examples.md`
  - `analysis/real-speaker-exemplars.md`

The output of the 30-minute version is simple:

- one diagnosis
- one baseline sample
- one rough score
- one next-week action

## 60-minute version

If the learner has more time, use this fuller first session.

### Step 1: Diagnose the problem

Use:

- `analysis/speaking-diagnosis-guide.md`

Choose the most accurate failure mode.

### Step 2: Record one baseline sample

Use:

- `analysis/speaking-sample-prompt-bank.md`

Pick one prompt family and record one short sample.

### Step 3: Self-score the sample

Use:

- `analysis/speaking-progress-scorecard.md`

Score the most relevant dimensions.

### Step 4: Get one outside reaction if possible

Use:

- `analysis/listener-feedback-template.md`

If no listener is available, skip this and continue.

### Step 5: Choose the first practice route

Use:

- `analysis/transcript-backed-concrete-speaking-approaches.md`
  if you want a named move before you pick a longer route
- `analysis/focused-improvement-actions.md`
  if you already know you want action-first practice
- `analysis/worked-speaking-situation-examples.md`
  if you need weak-versus-strong contrast before trying the move yourself

Pick one:

- `analysis/focused-improvement-actions.md`
  if you want the simplest immediate action
- `analysis/weekly-practice-sprints.md`
  if you want a one-week plan
- `analysis/month-one-speaking-training-plan.md`
  if you are ready for a more serious four-week start

If you still need stronger modeling before the first route:

- use `analysis/worked-speaking-situation-examples.md` for realistic weak
  versus strong replacements
- use `analysis/speaking-move-deployment-examples.md` if you want named speaker
  examples tied to exact work, pressure, humor, presentation, or social
  situations
- use `analysis/real-speaker-exemplars.md` for named source-backed speaker
  models
- use `analysis/real-world-speaking-application-examples.md` if you want the
  actual person, the matching real-life room, and a stronger version of what
  you could say
- use `analysis/speaking-roleplay-packs.md` if your real problem is what
  happens after the first answer, not before it

### Step 6: Write one commitment sentence

Examples:

- This week I am fixing rushed first sentences under pressure.
- This week I am fixing structure before adding more polish.
- This week I am working on workplace credibility, not humor.

The purpose is to stop the first session from turning into passive browsing.

## Best next routes by first-session result

If the baseline reveals pressure collapse:

- go to `Pathway 1`
- or `Sprint 1`
- and optionally `worked-speaking-situation-examples`
  `Situation 2`

If the baseline reveals rambling:

- go to `Pathway 2`
- or `Sprint 2`
- and optionally `worked-speaking-situation-examples`
  `Situation 1`

If the baseline reveals weak professional delivery:

- go to `Pathway 6`
- or `Sprint 3`
- and optionally `real-speaker-exemplars`
  `Vinh Giang` or `Guy Kawasaki`

If the baseline reveals social hesitation:

- go to `Pathway 4`
- or `Sprint 4`
- and optionally `worked-speaking-situation-examples`
  `Situation 5` or `Situation 10`

If the baseline reveals mistimed humor:

- stay with connection and timing work before trying bigger humor work
- and use `real-speaker-exemplars`
  `Chris Duffy / humor`

## What not to do in the first session

- do not open ten concept pages before recording anything
- do not choose drills based only on what sounds interesting
- do not start month-one planning before diagnosing the bottleneck
- do not use feelings alone as the baseline
