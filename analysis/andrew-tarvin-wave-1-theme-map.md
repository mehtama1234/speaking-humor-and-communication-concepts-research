## Strongest exact-approach bridges

This corpus most clearly appears to deepen:

- `Approach 5`
- `Approach 11`
- `Approach 17`
- `Approach 22`
- `Approach 24`

Likely sub-moves inside those approaches:

- use humor in service of message and memory
- avoid humor that distracts, divides, or disparages
- use comic triples rather than vague "be funny" advice
- iterate presentations in small improvements instead of waiting for a perfect version
- use improv games to train flexibility
