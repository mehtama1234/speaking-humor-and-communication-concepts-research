# Daily Speaking Session Templates

Concrete practice-session templates for turning the speaking atlas into
repeatable daily execution.

Date: August 10, 2026.

## Purpose

The repo already has:

- diagnosis
- weekly actions
- weekly sprints
- time-budget planning
- month-one sequencing

What it still needed was a stronger daily layer:

- what exactly should I do in one practice session today?

This file closes that gap.

## How to use these templates

- Pick one problem only.
- Pick one session length that you can actually finish.
- Use the same template for at least three sessions before redesigning it.
- End every session by writing the next rep, not by vaguely promising to
  practice again.

## Session Template 1: 10-minute rescue session

Best for:

- busy days
- rebuilding consistency
- learners likely to skip practice if the bar feels too high

Structure:

1. Spend 1 minute naming the one behavior you are fixing today.
2. Spend 3 minutes running one micro-drill.
3. Spend 1 minute checking one relevant example:
   - `analysis/transcript-backed-concrete-speaking-approaches.md` for the
     named transcript-backed move itself when you still do not know the exact
     behavior to rehearse
   - `analysis/worked-speaking-situation-examples.md` for a before/after
     situation
   - `analysis/speaking-move-deployment-examples.md` for a named speaker plus
     exact room-level deployment example
   - `analysis/real-speaker-exemplars.md` for a named speaker model
   - `analysis/real-world-speaking-application-examples.md` for a real
     speaker, a matching room, and a stronger borrowed version
   - `analysis/speaking-roleplay-packs.md` if your weakness appears most clearly
     after the follow-up turn
4. Spend 2 minutes recording one short answer, update, or story rep.
5. Spend 2 minutes replaying it and naming one visible win and one breakdown.
6. Spend 1 minute choosing tomorrow's first rep.

Good pairings:

- freezing: `pressure-question five-second reset`
- rambling: `PREP argument reps`
- weak work presence: `pause replacement reps`
- awkward conversation: `small-talk entry reps`

Live transfer upgrade:

- if the real bottleneck is not practice consistency but actually using the
  move this week, pair the session with one assignment from
  `analysis/live-field-missions.md`

## Session Template 2: 20-minute standard session

Best for:

- most working professionals
- learners who want a sustainable default
- anyone running a weekly sprint seriously

Structure:

1. Spend 2 minutes reviewing yesterday's note.
2. Spend 6 minutes on one drill or one action block.
3. Spend 2 minutes checking one example or exemplar that matches the target.
   If the target still feels fuzzy, spend that check on
   `analysis/transcript-backed-concrete-speaking-approaches.md` first and only
   then open an example or exemplar.
4. Spend 4 minutes on two recorded reps from the same prompt family.
5. Spend 4 minutes comparing rep one versus rep two.
6. Spend 2 minutes writing the exact focus for the next session.

What to compare:

- did the point arrive earlier?
- did the first sentence get calmer?
- did the delivery sound flatter or more alive?
- did you answer the question or circle it?

## Session Template 3: 30-minute transfer session

Best for:

- learners who can practice and then test transfer the same day
- people preparing for meetings, interviews, or live social situations

Structure:

1. Spend 3 minutes naming the real situation coming up.
2. Spend 4 minutes reviewing the closest matching item in
   `analysis/worked-speaking-situation-examples.md`.
   If you still need the exact move before the situation rewrite, start with
   one item from `analysis/transcript-backed-concrete-speaking-approaches.md`.
   If you need a stronger bridge from speaker model to real room, use one item
   from `analysis/speaking-move-deployment-examples.md` instead. If you want
   the person, the room, and the stronger borrowed version in one place, use
   `analysis/real-world-speaking-application-examples.md`.
3. Spend 6 minutes on the most relevant drill.
4. Spend 7 minutes recording one realistic version of the situation.
5. Spend 5 minutes rewriting and re-recording the same situation better.
6. Spend 5 minutes writing one live cue you will use when the real moment arrives.

Roleplay upgrade:

- if the real moment includes likely pushback or a harder second turn, swap the
  single-situation rep for one item from `analysis/speaking-roleplay-packs.md`
  and score it with `analysis/roleplay-feedback-scorecard.md`
- if you have a partner, run it with
  `analysis/partner-roleplay-facilitator-guide.md`

Best live cues:

- `pause before first sentence`
- `answer the question first`
- `land on the key word`
- `ask one follow-up before performing`
- `state the recommendation before the explanation`

## Session Template 4: 45-minute deep practice block

Best for:

- serious learners
- high-stakes preparation periods
- people using the month-one system as an actual training block

Structure:

1. Spend 5 minutes reviewing the target problem and current route.
2. Spend 5 minutes reviewing one matching section from
   `analysis/real-speaker-exemplars.md`.
   If the missing piece is not the model but the exact move, use
   `analysis/transcript-backed-concrete-speaking-approaches.md` first.
   If the missing piece is not admiration but exact transfer, swap this for
   `analysis/speaking-move-deployment-examples.md` or
   `analysis/real-world-speaking-application-examples.md`.
3. Spend 10 minutes drilling one behavior repeatedly.
4. Spend 10 minutes recording a baseline-style sample.
5. Spend 7 minutes reworking the weak spots and recording again.
6. Spend 4 minutes scoring the sample against the scorecard.
7. Spend 4 minutes writing the next session plan.

Do not use extra time to browse more content.

Use extra time to:

- repeat the same answer with better structure
- compare two openings
- improve one delivery line three different ways
- test the same cue in a harder prompt

## Session Template 5: Live-day tune-up

Best for:

- the day of a meeting, interview, presentation, or important conversation
- learners who need sharper execution, not a full training block

Structure:

1. Spend 3 minutes reviewing the event-specific checklist.
2. Spend 4 minutes reviewing the closest matching live example in
   `analysis/worked-speaking-situation-examples.md`.
   If the move itself still feels unclear, review one matching item in
   `analysis/transcript-backed-concrete-speaking-approaches.md` first.
3. Spend 4 minutes running only the opening or hardest question.
4. Spend 3 minutes stripping apology language, filler, and clutter.
5. Spend 4 minutes rehearsing the first answer or first story beat.
6. Spend 2 minutes writing three reminders you can carry into the room.

Roleplay upgrade:

- if the live event will likely include sharper follow-up pressure, run one
  roleplay pack instead of one single-turn answer and score it afterward with
  `analysis/roleplay-feedback-scorecard.md`
- if a second person is available, use
  `analysis/partner-roleplay-facilitator-guide.md` so the follow-up pressure
  stays realistic

Good reminder types:

- pace
- first sentence
- one-point answer
- pause after humor
- ask before over-explaining

## Recommended template by speaking problem

If your main problem is:

- freezing or panic: use Template 1 or Template 3
- rambling or unclear answers: use Template 2
- flat delivery or low energy: use Template 2 or Template 4
- work credibility: use Template 2 or Template 5
- social awkwardness or forced humor: use Template 3
- hard questions or objections: use Template 3 or Template 5

If your main problem still feels too abstract before you start:

- open `analysis/transcript-backed-concrete-speaking-approaches.md` first if
  you need the named move before you choose the example, drill, or roleplay
- open `analysis/worked-speaking-situation-examples.md` first if you need a
  live-situation model
- open `analysis/speaking-move-deployment-examples.md` first if you need a
  named speaker example already translated into a specific kind of room
- open `analysis/real-speaker-exemplars.md` first if you want to study a real
  speaker using the move well
- open `analysis/real-world-speaking-application-examples.md` first if you
  want a stronger borrowed version before recording your own rep

## Good default weekly pattern

If you do not want to design your own pattern, use:

- Monday: Template 2
- Tuesday: Template 1
- Wednesday: Template 3
- Thursday: Template 1
- Friday: Template 2
- weekend: one live rep plus one short review

## Daily session note template

Write five bullets after each session:

- target behavior
- drill used
- prompt or situation used
- one visible improvement
- one breakdown to carry forward

## Common mistakes

Do not:

- change the target problem every day
- use a different prompt family every session
- confuse reading with practice
- stop after one better rep and assume it has transferred
- end the session without naming tomorrow's first move
